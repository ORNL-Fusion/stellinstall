57 !
58 ! ictrl_flag = ictrl_array(1)
59 ! flag that controls calling of various subroutines of vmec code
60 ! add together the values beow to utilize several subroutines with one call
61 !
62 ! value flag-name calls routines to...
63 ! ----- --------- ---------------------
64 ! 1 restart_flag reset internal run-control parameters (for example, if
65 ! jacobian was bad, to try a smaller time-step)
66 ! 2 readin_flag read in data from input_file and initialize parameters/arrays
67 ! which do not dependent on radial grid size
68 ! allocate internal grid-dependent arrays used by vmec;
69 ! initialize internal grid-dependent vmec profiles (xc, iota, etc);
70 ! setup loop for radial multi-grid meshes or, if ns_index = ictrl_array(4)
71 ! is > 0, use radial grid points specified by ns_array[ns_index]
72 ! 4 timestep_flag iterate vmec either by "niter" time steps or until ftol satisfied,
73 ! whichever comes first. If numsteps (see below) > 0, vmec will return
74 ! to caller after numsteps, rather than niter, steps.
75 ! 8 output_flag write out output files (wout, jxbout)
76 ! 16 cleanup_flag cleanup (deallocate arrays) - this terminates present run of the sequence
77 ! This flag will be ignored if the run might be continued. For example,
78 ! if ier_flag (see below) returns the value more_iter_flag, the cleanup
79 ! code will be skipped even if cleanup_flag is set, so that the run
80 ! could be continued on the next call to runvmec.
81 ! 32 reset_jacdt_flag Resets ijacobian flag and time step to delt0
82 !
83 ! thus, setting ictrl_flag = 1+2+4+8+16 will perform ALL the tasks thru cleanup_flag
84 ! in addition, if ns_index = 0 and numsteps = 0 (see below), vmec will control its own run history
85 !
86 ! ier_flag = ictrl_array(2)
87 ! specifies vmec error condition (if nonzero)
88 ! numsteps = ictrl_array(3)
89 ! number time steps to evolve the equilibrium. Iterations will stop EITHER if numsteps > 0 and
90 ! when the number of vmec iterations exceeds numsteps; OR if the ftol condition is satisfied,
91 ! whichever comes first. The timestep_flag must be set (in ictrl_flag) for this to be in effect.
92 ! If numsteps <= 0, then vmec will choose consecutive (and increasing) values from the ns_array
93 ! until ftol is satisfied on each successive multi-grid.
94 ! ns_index = ictrl_array(4)
95 ! if > 0 on entry, specifies index (in ns_array) of the radial grid to be used for the present iteration
96 ! phase. If ns_index <= 0, vmec will use the previous value of this index (if the ftol
97 ! condition was not satisfied during the last call to runvmec) or the next value of this index,
98 ! and it will iterate through each successive non-zero member of the ns_array until ftol-convergence
99 ! occurs on each multigrid.
100 ! on exit, contains last value of ns_array index used
101 ! iseq_count=ictrl_array(5)
102 ! specifies a unique sequence label for identifying output files in a sequential vmec run
