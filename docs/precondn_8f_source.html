157 !
158 ! COMPUTE PRECONDITIONING MATRIX ELEMENTS FOR R,Z
159 ! FORCE. NOTE THAT THE NORMALIZATION IS:

161 ! AX(off-diag) ~ <(cosmui cosmu cosnv cosnv) 2(R**2*Xu**2*bsq/gsqrt)>
