Gets the guassian process kernel for a diagnostic and a position.

This method is meant to be overwritten by a subclass method. As a result, returns the get_gp method of the subclass instance diagnostic_class was constructed with. Only diagnostics that use te, ne, or sxrem profile have a valid implementation.

Gets the guassian process kernel for a diagnostic and a signal.

This method is meant to be overwritten by a subclass method. As a result, returns the get_gp method of the subclass instance diagnostic_class was constructed with. Only diagnostics that use te, ne, or sxrem profile have a valid implementation. The second signal was cast to a void pointer so it can be send to the subclass instance.
