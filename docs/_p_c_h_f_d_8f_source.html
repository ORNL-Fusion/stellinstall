35 !* **PURPOSE Evaluate a piecewise cubic Hermite function and its first
36 ! derivative at an array of points. May be used by itself
37 ! for Hermite interpolation, or as an evaluator for PCHIM
38 ! or PCHI!. If only function values are required, use
39 ! PCHFE instead.
40 !* **DESCRIPTION
41 !
42 ! PCHFD: Piecewise Cubic Hermite Function and Derivative
43 ! evaluator
44 !
45 ! Evaluates the cubic Hermite FUNCTION defined by N, X, F, D, to-
46 ! gether with its first derivative, at the points XE(J), J=1(1)NE.
47 !
48 ! If only function values are required, Use PCHFE, instead.
49 !
50 ! To provide compatibility with PCHIM and PCHIC, includes an
51 ! increment between successive values of the F- and D-arrays.
52 !
53 C ----------------------------------------------------------------------
54 !
55 ! Calling sequence:
56 !
57 ! PARAMETER (INCFD = ...)
58 ! INTEGER N, NE, IERR
59 ! REAL X(N), F(INCFD,N), D(INCFD,N), XE(NE), FE(NE), DE(NE)
60 ! LOGICAL SKIP
61 !
62 ! CALL PCHFD (N, X, F, D, INCFD, SKIP, NE, XE, FE, DE, IERR)
63 !
64 ! Parameters:
65 !
66 ! N -- (input) number of data points. (Error RETURN IF N.LT.2 .)
67 !
68 ! X -- (input) REAL array of independent variable values. The
69 ! elements of X must be strictly increasing:
70 ! X(I-1) .LT. X(I), I = 2(1)N.
71 ! (Error RETURN IF not.)
72 !
73 ! F -- (input) REAL array of FUNCTION values. F(1+(I-1)*INCFD) is
74 ! the value corresponding to X(I).
75 !
76 ! D -- (input) REAL array of derivative values. D(1+(I-1)*INCFD) is
77 ! the value corresponding to X(I).
78 !
79 ! INCFD -- (input) increment between successive values in F and D.
80 ! (Error RETURN IF INCFD.LT.1 .)
81 !
82 ! SKIP -- (input/output) LOGICAL variable which should be set to
83 ! .TRUE. IF the user wishes to skip checks for validity of
84 ! preceding parameters, or to .FALSE. otherwise.
85 ! This will SAVE time in CASE these checks have already
86 ! been performed (say, in PCHIM or PCHIC).
87 ! SKIP will be set to .TRUE. on normal RETURN.
88 !
89 ! NE -- (input) number of evaluation points. (Error RETURN IF
90 ! NE.LT.1 .)
91 !
92 ! XE -- (input) real array of points at which the functions are to
93 ! be evaluated.
94 !
95 !
96 ! NOTES:
97 ! 1. The evaluation will be most efficient If the elements
98 ! of XE are increasing relative to X;
99 ! that is, XE(J) .GE. X(I)
100 ! implies XE(K) .GE. X(I), ALL K.GE.J .
101 ! 2. If any of the XE are outside the interval [X(1),X(N)],
102 ! values are extrapolated from the nearest extreme cubic,
103 ! and a warning error is returned.
104 !
105 ! FE -- (output) REAL array of values of the cubic Hermite FUNCTION
106 ! defined by N, X, F, D at the points XE.
107 !
108 ! DE -- (output) REAL array of values of the first derivative of
109 ! the same FUNCTION at the points XE.
110 !
111 ! IERR -- (output) error flag.
112 ! Normal RETURN:
113 ! IERR = 0 (no errors).
114 ! Warning error:
115 ! IERR.GT.0 means that extrapolation was performed at
116 ! IERR points.
117 ! "Recoverable" errors:
118 ! IERR = -1 IF N.LT.2 .
119 ! IERR = -2 IF INCFD.LT.1 .
120 ! IERR = -3 IF the X-array is not strictly increasing.
121 ! IERR = -4 IF NE.LT.1 .
122 ! (Output arrays have not been changed in any of these cases.)
123 ! NOTE: The above errors are checked in the order listed,
124 ! and following arguments have **NOT*! been validated.
125 ! IERR = -5 IF an error has occurred in the lower-level
126 ! routine CHFDV. NB: this should never happen.
127 ! Notify the author **IMMEDIATELY*! if it does.
128 !
129 !* **REFERENCES (NONE)
130 !* **ROUTINES CALLED CHFDV
131 !* **END PROLOGUE PCHFD

134 !
135 ! Change record:
136 ! 82-08-03 Minor cosmetic changes for release 1.
137 ! 87-07-07 Minor cosmetic changes to prologue.

139 ! ----------------------------------------------------------------------

141 ! Programming notes:
142 !
143 ! 1. To produce a Double precision version, simply:
144 ! a. Change PCHFD to DPCHFD, and CHFDV to DCHFDV, wherever they
145 ! occur,
146 ! b. Change the real declaration to Double precision,
147 !
148 ! 2. Most of the coding between the call to CHFDV and the end of
149 ! the IR-loop could be eliminated if it were permissible to
150 ! assume that XE is ordered relative to X.
151 !
152 ! 3. CHFDv does not assume that X1 is less than X2. thus, it would
153 ! be possible to write a version of PCHFD that assumes a strict-
154 ! ly decreasing X-array by simply running the IR-loop backwards
155 ! (and reversing the order of appropriate tests).
156 !
157 ! 4. The present code has a minor bug, which i have decided is not
158 ! worth the effort that would be required to fix it.
159 ! If XE contains points in [X(N-1),X(N)], followed by points .LT.
160 ! X(N-1), followed by points .GT.X(N), the extrapolation points
161 ! will be counted (at least) twice in the total returned in IERR.
162 !

164 !
165 !

168 !
169 ! VALIDITY-CHECK ARGUMENTS.

172  IF (.NOT.skip) THEN
173 !
174  IF (n < 2) GO TO 5001
175  IF (incfd < 1) GO TO 5002
176  DO i = 2, n
177  IF (x(i) <= x(i-1)) GO TO 5003
178  END DO
179 !
180 ! FUNCTION DEFINITION IS OK, GO ON.
181 !
182  ENDIF
183  IF (ne < 1) GO TO 5004
184  ierr = 0
185  skip = .true.
186 !
187 ! LOOP OVER INTERVALS. ( INTERVAL INDEX IS IL = IR-1 . )
188 ! ( INTERVAL IS X(IL).LE.X.LT.X(IR) . )
189  jfirst = 1
190  ir = 2
191  10 CONTINUE
192 !
193 ! SKIP OUT OF LOOP IF HAVE PROCESSED ALL EVALUATION POINTS.
194 !
195  IF (jfirst > ne) GO TO 5000
196 !
197 ! LOCATE ALL POINTS IN INTERVAL.
198 !
199  DO j = jfirst, ne
200  IF (xe(j) >= x(ir)) GO TO 30
201  END DO
202  j = ne + 1
203  GO TO 40
204 !
205 ! HAVE LOCATED FIRST POINT BEYOND INTERVAL.
206 !
207  30 CONTINUE
208  IF (ir == n) j = ne + 1

221  1 d(1,ir-1), d(1,ir), nj, xe(jfirst), fe(jfirst),
222  2 de(jfirst), next, ierc)

224  IF (ierc < 0) GO TO 5005
225 !

228 ! IN THE CURRENT SET OF XE-POINTS, THERE ARE NEXT(2) TO THE
229 ! RIGHT OF X(IR).
230 !

233 ! THESE ARE ACTUALLY EXTRAPOLATION POINTS.
234  ierr = ierr + next(2)
235  ELSE
236 ! ELSE
237 ! WE SHOULD NEVER HAVE GOTTEN HERE.

239 ! ENDIF
240 ! ENDIF
241  ENDIF
242  ENDIF
243 !

246 ! IN THE CURRENT SET OF XE-POINTS, THERE ARE NEXT(1) TO THE
247 ! LEFT OF X(IR-1).
248 !
249  IF (ir .LE. 2) THEN
250 ! IF (IR .EQ. 2) THEN
251 ! THESE ARE ACTUALLY EXTRAPOLATION POINTS.
252  ierr = ierr + next(1)
253  ELSE
254 ! ELSE
255 ! XE IS NOT ORDERED RELATIVE TO X, SO MUST ADJUST
256 ! EVALUATION INTERVAL.
257 !

259  DO i = jfirst, j - 1

261  END DO

263 ! IN CHFDV.
264  GO TO 5005
265 !
266  45 CONTINUE
267 ! RESET J. (THIS WILL BE THE NEW JFIRST.)
268  j = i
269 !
270 ! NOW FIND OUT HOW FAR TO BACK UP IN THE X-ARRAY.
271  DO i = 1, ir - 1
272  IF (xe(j) < x(i)) EXIT
273  END DO
274 ! AT THIS POINT, EITHER XE(J) .LT. X(1)
275 ! OR X(I-1) .LE. XE(J) .LT. X(I) .
276 ! RESET IR, RECOGNIZING THAT IT WILL BE INCREMENTED BEFORE

279 ! ENDIF
280 ! ENDIF
281  ENDIF
282  ENDIF
283 !

287 !

295  RETURN

303  RETURN
304 !
305  5002 CONTINUE

307  ierr = -2
308  stop 'PCHFD -- INCREMENT LESS THAN ONE'
309  RETURN
310 !
311  5003 CONTINUE
312 ! X-ARRAY NOT STRICTLY INCREASING.
313  ierr = -3
314  stop 'PCHFD -- X-ARRAY NOT STRICTLY INCREASING'
315  RETURN
316 !
317  5004 CONTINUE
318 ! NE.LT.1 RETURN.
319  ierr = -4
320  stop 'PCHFD -- NUMBER OF EVALUATION POINTS LESS THAN ONE'
321  RETURN
322 !
323  5005 CONTINUE

325 ! **! THIS CASE SHOULD NEVER OCCUR ***
326  ierr = -5
