Construct a limiter containing an iso function.

Allocates memory and initializes a limiter_class object.

Parameters
[in]isoA contour function to define the limiter.
[in]on_edgeSpecifies if the edge should touch the limiter or not. If true, the reconstruction tries to have the limiter touch the limiter. If false, the edge will only just fall inside the limiter.
Returns
A pointer to a constructed limiter_class object.

real (rprec) function, dimension(4) limiter::limiter_get_modeled_iso_signal ( type (limiter_class), intent(in)  this,
type (model_class), intent(in)  a_model,
real (rprec), dimension(4), intent(out)  sigma 
)

Calculates the modeled signal from an iso function.

If limiter_class::on_edge or the plasma edge extends beyond the limiter, returns the R, Phi and Z posiiton of the maximum of the iso function value. Otherwise returns zero.

The R and Z positions for a fixed toroidal plane are retrived from the the equilibrium method equilibrium_get_plasma_edge
Parameters
[in]thisA limiter_class instance.
[in]a_modelA model instance.
[out]sigmaReturns the value of modeled sigma.
Returns
If limiter_class::on_edge or the plasma edge extends beyond the limiter, returns the R, Phi and Z posiiton of the maximum of the iso function value. Otherwise returns zero.
Note
Polygon limiters have not be implemented yet.

Returns
