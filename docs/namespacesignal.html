Detailed Description

Defines the base class of the type signal_class and the base class of combination_class and gaussp_class.

signal Sub Classes: magnetic, sxrem, intpol, thomson, extcurz, mse, ece, limiter, prior_gaussian, and feedback
combination Super Class: signal
Note
Combination and Gaussian process are defined in the signal module to avoid a circular module dependency.
