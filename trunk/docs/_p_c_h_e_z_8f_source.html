6 !-----------------------------------------------
7  INTEGER :: n, lwk, ierr

13 !-----------------------------------------------
14  INTEGER, DIMENSION(2) :: ic
15  INTEGER :: incfd
16  REAL(rprec), DIMENSION(2) :: vc
17 !-----------------------------------------------
18 !***BEGIN PROLOGUE PCHEZ
19 !***DATE WRITTEN 870821 (YYMMDD)
20 !***REVISION DATE 870908 (YYMMDD)
21 !***CATEGORY NO. E1B
22 !***KEYWORDS CUBIC HERMITE MONOTONE INTERPOLATION, SPLINE
23 ! INTERPOLATION, EASY TO USE PIECEWISE CUBIC INTERPOLATION
24 !***AUTHOR KAHANER, D.K., (NBS)
25 ! SCIENTIFIC COMPUTING DIVISION
26 ! NATIONAL BUREAU OF STANDARDS
27 ! GAITHERSBURG, MARYLAND 20899
28 ! (301) 975-3808
29 !***PURPOSE Easy to USE spline or cubic Hermite interpolation.
30 !***DESCRIPTION
31 !
32 ! PCHEZ: Piecewise Cubic Interpolation, Easy to Use.
33 !
34 ! From the book "Numerical Methods and Software"
35 ! by D. Kahaner, C. Moler, S. Nash
36 ! Prentice HALL 1988
37 !
38 ! Sets derivatives for spline (two continuous derivatives) or
39 ! Hermite cubic (one continuous derivative) interpolation.
40 ! Spline interpolation is smoother, but may not "look" right IF the
41 ! data CONTAINS both "steep" and "flat" sections. Hermite cubics
42 ! can produce a "visually pleasing" and monotone interpolant to
43 ! monotone data. This is an easy to USE driver for the routines
44 ! by F. N. Fritsch in reference (4) below. Various boundary
45 ! conditions are set to DEFAULT values by PCHEZ. MANY other choices
46 ! are available in the SUBROUTINEs PCHIC, PCHIM and PCHSP.
47 !
48 ! Use PCHEV to evaluate the resulting function and its derivative.
49 !
50 ! ----------------------------------------------------------------------
51 !
52 ! Calling sequence: CALL PCHEZ (N, X, F, D, SPLINE, WK, LWK, IERR)
53 !
54 ! INTEGER N, IERR, LWK
55 ! REAL X(N), F(N), D(N), WK(*)
56 ! LOGICAL SPLINE
57 !
58 ! Parameters:
59 !
60 ! N -- (input) number of data points. (Error RETURN IF N.LT.2 .)
61 ! If N=2, simply does linear interpolation.
62 !
63 ! X -- (input) REAL array of independent variable values. The
64 ! elements of X must be strictly increasing:
65 ! X(I-1) .LT. X(I), I = 2(1)N.
66 ! (Error RETURN IF not.)
67 !
68 ! F -- (input) REAL array of dependent variable values to be inter-
69 ! polated. F(I) is value corresponding to X(I).
70 !
71 ! D -- (output) REAL array of derivative values at the data points.
72 !
73 ! SPLINE -- (input) LOGICAL variable to specify IF the interpolant
74 ! is to be a spline with two continuous derivaties
75 ! (set SPLINE=.TRUE.) or a Hermite cubic interpolant with one
76 ! continuous derivative (set SPLINE=.FALSE.).
77 ! Note: If SPLINE=.TRUE. the interpolating spline satisfies the
78 ! DEFAULT "not-a-knot" boundary condition, with a continuous
79 ! third derivative at X(2) and X(N-1). See reference (3).
80 ! If SPLINE=.FALSE. the interpolating Hermite cubic will be
81 ! monotone IF the input data is monotone. Boundary conditions
82 ! computed from the derivative of a local quadratic unless this
83 ! alters monotonicity.
84 !
85 ! WK -- (scratch) REAL work array, which must be declared by the calling
86 ! program to be at least 2*N IF SPLINE is .TRUE. and not used
87 ! otherwise.
88 !
89 ! LWK -- (input) length of work array WK. (Error RETURN IF
90 ! LWK.LT.2*N and SPLINE is .TRUE., not checked otherwise.)
91 !
92 ! IERR -- (output) error flag.
93 ! Normal RETURN:
94 ! IERR = 0 (no errors).
95 ! Warning error:
96 ! IERR.GT.0 (can ONLY occur when SPLINE=.FALSE.) means that
97 ! IERR switches in the direction of monotonicity were detected.
98 ! When SPLINE=.FALSE., PCHEZ guarantees that IF the input
99 ! data is monotone, the interpolant will be too. This warning
100 ! is to alert you to the fact that the input data was not
101 ! monotone.
102 ! "Recoverable" errors:
103 ! IERR = -1 IF N.LT.2 .
104 ! IERR = -3 IF the X-array is not strictly increasing.
105 ! IERR = -7 IF LWK is less than 2*N and SPLINE is .TRUE.
106 ! (The D-array has not been changed in any of these cases.)
107 ! NOTE: The above errors are checked in the order listed,
108 ! and following arguments have **NOT** been validated.
109 !
110 !----------------------------------------------------------------------
111 !***REFERENCES 1. F.N.FRITSCH AND R.E.CARLSON, 'MONOTONE PIECEWISE CUBIC INTERPOLATION,'
112 ! SIAM J.NUMER.ANAL. 17, 2 (APRIL 1980), 238-246.
113 ! 2. F.N.FRITSCH AND J.BUTLAND, 'A METHOD FOR CONSTRUCTING LOCAL MONOTONE PIECEWISE CUBIC INTERPOLANTS,'
114 ! LLNL PREPRINT UCRL-87559 (APRIL 1982).
115 ! 3. CARL DE BOOR, A PRACTICAL GUIDE TO SPLINES, SPRINGER-
116 ! VERLAG (NEW YORK, 1978). (ESP. CHAPTER IV, PP.49-62.)
117 ! 4. F.N.FRITSCH, 'PIECEWISE CUBIC HERMITE INTERPOLATION PACKAGE, FINAL SPECIFICATIONS',
118 ! LAWRENCE LIVERMORE NATIONAL LABORATORY, COMPUTER DOCUMENTATION UCID-30194, AUGUST 1982.
119 !***ROUTINES CALLED PCHIM,PCHSP
120 !***END PROLOGUE PCHEZ
121 !
122 ! DECLARE LOCAL VARIABLES.
123 !
124  ic = 0; incfd = 1
125 !
126 !***FIRST EXECUTABLE STATEMENT PCHEZ
127 !
128  IF (spline) THEN
129  CALL pchsp (ic, vc, n, x, f, d, incfd, wk, lwk, ierr)
130  ELSE
131  CALL pchim (n, x, f, d, incfd, ierr)
132  ENDIF
133 !
134 ! ERROR CONDITIONS ALREADY CHECKED IN PCHSP OR PCHIM
135 
136  RETURN
137 !------------- LAST LINE OF PCHEZ FOLLOWS ------------------------------
138  END SUBROUTINE pchez
