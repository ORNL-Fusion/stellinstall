41 ! Evaluates the function and first derivative of the cubic Hermite
42 ! or spline function defined by N, X, F, D, at the array of points
43 !
44 ! This is an easy to use driver for the routines by F.N. Fritsch
45 ! described in reference (2) below. Those also have other capabilities.
46 !
47 ! ----------------------------------------------------------------------
48 !
49 ! Calling sequence: CALL PCHEV (N, X, F, D, NVAL, XVAL, FVAL, DVAL, IERR)
50 !
51 ! INTEGER N, NVAL, IERR
52 ! REAL X(N), F(N), D(N), XVAL(NVAL), FVAL(NVAL), DVAL(NVAL)
53 !
54 ! Parameters:
55 !
56 ! N -- (input) number of data points. (Error RETURN IF N.LT.2 .)
57 !
58 ! X -- (input) REAL array of independent variable values. The
59 ! elements of X must be strictly increasing:
60 ! X(I-1) .LT. X(I), I = 2(1)N. (Error RETURN IF not.)
61 !
62 ! F -- (input) REAL array of FUNCTION values. F(I) is
63 ! the value corresponding to X(I).
64 !
65 ! D -- (input) REAL array of derivative values. D(I) is
66 ! the value corresponding to X(I).
67 !
68 ! NVAL -- (input) number of points at which the functions are to be
69 ! evaluated. ( error return if nval.lt.1 )
70 !
71 ! XVAL -- (input) real array of points at which the functions are to
72 ! be evaluated.
73 !
74 ! NOTES:
75 ! 1. The evaluation will be most efficient if the elements
76 ! of XVAL are increasing relative to X;
77 ! that is, XVAL(J) .GE. X(I)
78 ! implies XVAL(K) .GE. X(I), ALL K.GE.J .
79 ! 2. If any of the XVAL are outside the interval [X(1),X(N)],
80 ! values are extrapolated from the nearest extreme cubic,
81 ! and a warning error is returned.
82 !
83 ! FVAL -- (output) REAL array of values of the cubic Hermite function
84 ! defined by N, X, F, D at the points XVAL.
85 !
86 ! DVAL -- (output) REAL array of values of the first derivative of
87 ! the same function at the points XVAL.
88 !
89 ! IERR -- (output) error flag.
90 ! Normal RETURN:
91 ! IERR = 0 (no errors).
92 ! Warning error:
93 ! IERR.GT.0 means that extrapolation was performed at
94 ! IERR points.
95 ! "Recoverable" errors:
96 ! IERR = -1 IF N.LT.2 .
97 ! IERR = -3 IF the X-array is not strictly increasing.
98 ! IERR = -4 IF NVAL.LT.1 .
99 ! (Output arrays have not been changed in any of these cases.)
100 ! NOTE: The above errors are checked in the order listed,
101 ! and following arguments have **NOT*! been validated.
102 ! IERR = -5 IF an error has occurred in the lower-level
103 ! routine CHFDV. NB: this should never happen.
104 ! Notify the author **IMMEDIATELY*! If it does.
105 !
106 ! ----------------------------------------------------------------------
107 !* **REFERENCES 1. F.N.FRITSCH AND R.E.CARLSON, 'MONOTONE PIECEWISE CUBIC INTERPOLATION,'
