type (model_class), intent(inout)  a_model,
real (rprec), dimension(4), intent(out)  sigma 
)

Calculates the modeled signal from an iso function.

If limiter_class::on_edge or the plasma edge extends beyond the limiter, returns the R, Phi and Z posiiton of the maximum of the iso function value. Otherwise returns zero.

The R and Z positions for a fixed toroidal plane are retrived from the the equilibrium method equilibrium_get_plasma_edge
Parameters
[in]thisA limiter_class instance.
