285 !=======Choice of strategy=================================================
286 ! We have tried to come up with a sensible naming-convention: DE/x/y/z
287 ! DE : stands for Differential Evolution
288 ! x : a string which denotes the vector to be perturbed
289 ! y : number of difference vectors taken for perturbation of x
290 ! z : crossover method (exp = exponential, bin = binomial)
291 !
292 ! There are some simple rules which are worth following:
293 ! 1) F is usually between 0.5 and 1 (in rare cases > 1)
294 ! 2) CR is between 0 and 1 with 0., 0.3, 0.7 and 1. being worth to be tried first
295 ! 3) To start off NP = 10*D is a reasonable choice. Increase NP IF
296 ! misconvergence happens.
297 ! 4) If you increase NP, F usually has to be decreased
298 ! 5) When the DE/best... schemes fail DE/rand... usually works and vice versa
299 !
300 !
301 ! Here are Storn''s comments on the different strategies:
302 !
303 ! (1) DE/best/1/'z'
304 ! Our oldest strategy but still not bad. However, we have found several
305 ! optimization problems WHERE misconvergence occurs.
306 !
307 ! (2) DE/rand/1/'z'
308 ! This is one of my favourite strategies. It works especially well when the
309 ! "bestit[]"-schemes EXPerience misconvergence. Try e.g. F=0.7 and CR=0.5
310 ! as a first guess.
311 !
312 ! (3) DE/rand-to-best/1/'z'
313 ! This strategy seems to be one of the best strategies. Try F=0.85 and CR=1.
314 ! If you get misconvergence try to increase NP. If this does not help you
315 ! should play around with all three control variables.
316 !
317 ! (4) DE/best/2/'z' is another powerful strategy worth trying
318 !
319 ! (5) DE/rand/2/'z' seems to be a robust optimizer for many functions
320 !
321 !===========================================================================
